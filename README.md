### 🧠 Featured NLP Project: `loosely-swahili`

[![PyPI](https://img.shields.io/pypi/v/loosely-swahili?color=blue&logo=pypi&logoColor=white)](https://pypi.org/project/loosely-swahili/)
[![Hugging Face](https://img.shields.io/badge/%F0%9F%A4%97-Hugging%20Face-FFD21E)](https://huggingface.co/loosely-swahili)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

**`loosely-swahili`** is an open-source Python Natural Language Processing (NLP) toolkit and morphological engine designed specifically for **East African code-switching, Sheng’, and localized Swahili dialects**.

* 🔍 **Morphological Parsing & Tokenization:** Bridges the gap where traditional NLP libraries (spaCy, NLTK) fail on hybrid English-Swahili agglutinative words (e.g., *"nime-book"*).
* 🤖 **AI Instruction Datasets:** Hosts specialized datasets like `kenyan-code-switch-instruct-50k` on Hugging Face to fine-tune Large Language Models (LLMs) on real-world East African communication.
* 📦 **Install via PyPI:** `pip install loosely-swahili`
